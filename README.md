# 🌱 KrishiMitra AI

KrishiMitra AI is an AI-powered agricultural advisory assistant designed to help farmers make informed farming decisions through intelligent, accessible, and multilingual guidance.

It combines Generative AI, weather information, soil analysis, and agricultural knowledge to provide practical recommendations based on a farmer's crop, location, and farming conditions.

### Key Features
- **AI Farming Assistant:** Answers farming-related questions and provides personalized crop guidance.
- **Multilingual Support:** Makes agricultural information accessible in Hindi and English.
- **Weather Insights:** Provides weather-related information to support farming decisions.
- **Soil Health Dashboard:** Allows farmers to enter soil parameters and receive AI-powered explanations.
- **Crop Scheduling:** Generates stage-wise crop schedules and farming guidance.
- **Disease Detection:** Analyzes uploaded crop images to identify possible disease symptoms.
- **RAG-based Knowledge Retrieval:** Uses agricultural reference documents to support relevant responses.
- **Voice Interaction:** Allows farmers to ask questions using voice input.

### Tech Stack
Python · Streamlit · Google Gemini API · LangChain · RAG · FAISS · Weather API
